## دەربارەی پرۆژەکە

**جریوە** موزیک پلەیەرێکە کە ڕاستەوخۆ لە براوزەر کار دەکات و پێویستی بە سێرڤەر نییە. فایلە دەنگییەکانی ئامێرەکەت زیاد دەکەیت و لێیان دەدەیت. ڕووکارەکەی ڕاستەوخۆ بە کوردی سۆرانییە (RTL)، و وەک ئەپێکی ئاسایی لەسەر مۆبایل و کۆمپیوتەر دادەمەزرێت.

هیچ فایلێکی دەنگی بۆ هیچ سێرڤەرێک نانێردرێت. هەموو شتێک لەناو براوزەری خۆتدا دەمێنێتەوە.

## تایبەتمەندییەکان

- ڕووکاری سادە و پاک، بە ڕووناک و تاریک (بە شێوەی خۆکار دەگۆڕێت یان بە دوگمە)
- ئەنیمەیشنی ڕووپۆشی گۆرانی لە کاتی لێداندا، و لیستی بێ scrollbar
- گواستنەوەی نەرم لەنێوان بەشەکان (سەرەکی، گەڕان، هونەرمەندان، لیستەکان، دڵخوازەکان، نوێترین)
- زیادکردنی فایل بە دوگمە یان ڕاکێشان (drag & drop)
- پشتگیری لە زۆربەی فۆرماتە دەنگییەکان، لەگەڵ **ffmpeg.wasm** وەک یەدەگ
- **گۆرانییەکان دەمێننەوە:** دوای داخستن و کردنەوەی ئەپەکە، لیستەکە، دڵخوازەکان و نوێترین بە IndexedDB هەڵدەگیرێن
- دوگمەی دڵخواز و سڕینەوە بۆ گۆرانی لێدراو
- **وێنەی ڕووپۆشی ناو فایلەکان** (MP3/ID3، FLAC، M4A) لە لای ڕاستی هەر گۆرانییەک پیشان دەدرێت
- **ڕێکخستنەکان:** زمانی ڕووکار (کوردی سۆرانی، فارسی، English)، ڕووکار و شێوەی پیشاندانی لیست
- **شێوەی پیشاندانی لیست:** لیست، چڕ، تۆڕ (Grid) و گەورە
- **دیاریکردنی بەکۆمەڵ** بۆ سڕینەوە، و دۆزینەوە و لابردنی گۆرانییە دووبارەکان
- کۆنتڕۆڵی تێکەڵ، پێشوو، دواتر، دووبارەکردنەوە (کوژاوە / هەموو لیست / یەک گۆرانی)، شوێنی گۆرانی و دەنگ
- کلیلە کورتەکان: `Space` بۆ لێدان/وەستان، تیرەکانی چەپ و ڕاست بۆ ٥ چرکە پێشکەوتن/دواکەوتن
- Media Session: کۆنتڕۆڵی گۆرانی لەسەر شاشەی قفڵ و کیبۆردی میدیا
- دادەمەزرێت وەک PWA و دوای یەکەم جار بێ ئینتەرنێت دەکرێتەوە

## کارکردن بێ ئینتەرنێت

- دوای **یەکەم جار** کردنەوەی ئەپەکە لەسەر `https` (وەک GitHub Pages) یان `localhost`، service worker هەموو فایلە سەرەکییەکان و فۆنتەکە هەڵدەگرێت و ئەپەکە بێ ئینتەرنێتیش دەکرێتەوە. گۆرانییەکان لە IndexedDB دا هەڵگیراون و بێ ئینتەرنێت دەلێدرێن.
- ئەگەر ئەپەکە بە `http://` (جگە لە localhost) یان ڕاستەوخۆ وەک فایل (`file://`) بکرێتەوە، service worker کار ناکات و بێ ئینتەرنێت ناکرێتەوە.
- ئەگەر `./setup-ffmpeg.sh` ت ڕاکێشابێت، فایلەکانی ffmpeg ـیش لەگەڵ ئەپەکە هەڵدەگیرێن بۆ ئەوەی ڕاستەوخۆ بێ ئینتەرنێت کار بکەن.
- دوای نوێکردنەوەی کۆد، ئەپەکە جاری یەکەم وەشانی کۆن نیشان دەدات و جاری دووەم نوێ دەبێتەوە.

## فۆرماتە پشتگیریکراوەکان

| ڕێگا | فۆرمات |
|---|---|
| براوزەر خۆی دەیخوێنێتەوە | MP3، AAC / M4A، WAV، OGG، Opus، WebM، و لە زۆربەی براوزەرەکان FLAC |
| ffmpeg.wasm دەیگۆڕێت بۆ WAV | WMA، APE، WV، AIFF، AMR، MKA، AC3، DTS، TTA و فۆرماتی تر |

لە سەرەتادا هەمیشە براوزەر هەوڵ دەدات خۆی فایلەکە بخوێنێتەوە. تەنیا ئەگەر نەیتوانی، ffmpeg بار دەکرێت و فایلەکە دەگۆڕێت. ئەمە لەسەر فایلە گەورەکان کەمێک کات دەگرێت.

## ڕێکخستنی پرۆژەکە

### ١. لەسەر کۆمپیوتەرەکەت

PWA پێویستی بە `https` یان `localhost` هەیە. ڕاستەوخۆ فایلی `index.html` بکەرەوە بۆ تاقیکردنەوە، بەڵام service worker تەنیا لەسەر سێرڤەر کار دەکات:

```bash
git clone https://github.com/USERNAME/deng.git
cd deng
python3 -m http.server 8080
```

پاشان `http://localhost:8080` بکەرەوە.

### ٢. بڵاوکردنەوە لەسەر GitHub Pages

1. پرۆژەکە بنێرە بۆ ڕیپۆیەکی GitHub.
2. بڕۆ بۆ **Settings ← Pages**.
3. لە **Source** هەڵبژێرە `Deploy from a branch`، پاشان لقی `main` و بوخچەی `/ (root)`.
4. چەند خولەکێک چاوەڕێ بکە. ئەپەکە لەم ناونیشانەدا دەبێت:
   `https://USERNAME.github.io/deng/`

### ٣. چالاککردنی ffmpeg بە شێوەی ناوخۆیی

بۆ ئەوەی ffmpeg بە باشی کار بکات، باشترە فایلەکانی لەسەر هەمان دۆمەینی خۆت بن. پێویستت بە [Node.js](https://nodejs.org) هەیە:

```bash
./setup-ffmpeg.sh
```

ئەم سکریپتە فایلەکانی `@ffmpeg/ffmpeg` و `@ffmpeg/core` دادەبەزێنێت و دەیانخاتە ناو `vendor/`. پاشان بوخچەی `vendor/` لەگەڵ کۆدەکە بنێرە بۆ GitHub.

ئەگەر ئەم هەنگاوە نەکەیت، ئەپەکە هەوڵ دەدات لە CDN ـی jsDelivr بارکردنی بکات. بەڵام ڕەنگە لەسەر هەندێک شوێن کار نەکات، چونکە worker ی ffmpeg دەبێت لە هەمان دۆمەینەوە بێت.

## ڕێکخستنی بوخچەکان

```text
deng/
├── index.html              # ئەپەکە (HTML، CSS و JavaScript لە یەک فایلدا)
├── manifest.webmanifest    # زانیاری PWA
├── sw.js                   # service worker بۆ کارکردن بێ ئینتەرنێت
├── setup-ffmpeg.sh         # دابەزاندنی ffmpeg.wasm بۆ vendor/
├── icons/                  # ئایکۆنەکان
├── vendor/                 # فایلەکانی ffmpeg.wasm (دوای setup-ffmpeg.sh)
├── LICENSE
└── README.md
```

## سنوورەکان

- **هەڵگرتن:** فایلەکان لەناو IndexedDB ـی براوزەرەکەتدا دەکۆپی دەکرێن، بۆیە شوێنی خۆی دەگرێت. ئەگەر داتای براوزەر بسڕیتەوە، گۆرانییەکانیش دەسڕێنەوە. هەروەها لە مۆدی Private/Incognito هەڵناگیرێن.
- **ناو و هونەرمەند:** لە ناوی فایلەکە وەردەگیرێن، بە شێوازی `Artist - Title`. تاگەکانی ناو فایلەکە (ID3) ناخوێنرێنەوە.
- **ffmpeg.wasm:** لەسەر فایلی گەورە یان ئامێری لاواز هێواشە، و لە هەندێک براوزەری کۆن کار ناکات.
- **ڕووپۆشی گۆرانی:** ئەگەر فایلەکە وێنەی ناوخۆی نەبێت، ڕەنگێکی گرادیەنت بەپێی ناوی گۆرانییەکە پیشان دەدرێت.
- **دووبارەکان:** گۆرانییەک بە دووبارە دادەنرێت ئەگەر قەبارەی فایلەکەی یان ناو و هونەرمەندەکەی وەک گۆرانییەکی تر بێت. پێش سڕینەوە دەتوانیت لە دۆخی دیاریکردندا پێداچوونەوەیان بکەیت.
